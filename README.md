# My Calories - iOS Calorie Tracker (Yazio Alternative)

Это нативное iOS-приложение для подсчета калорий, белков, жиров и углеводов. В приложении есть интеграция с открытой базой продуктов **OpenFoodFacts**, сканер штрих-кодов и синхронизация с **Apple Health** (Здоровье).

## Функции
- **Главный экран (Сводка)**: Красивые круговые графики калорий и прогресс-бары для макронутриентов (БЖУ).
- **Трекер воды**: Удобное добавление выпитой воды с сохранением в Apple Health.
- **Дневник питания**: Распределение еды по приемам (завтрак, обед, ужин, перекус).
- **Поиск еды и Сканер штрихкодов**: Интеграция с огромной бесплатной базой OpenFoodFacts.
- **Apple Health (HealthKit)**: Автоматическая синхронизация съеденной еды и воды с приложением "Здоровье", а также чтение сожженных калорий.

## 🚀 Как установить на iPhone БЕСПЛАТНО (на 7 дней) без аккаунта разработчика

Так как у вас **Mac**, установка приложения на ваш iPhone займет всего пару минут через официальную программу Apple — **Xcode**.

### Шаг 1: Скачайте Xcode
1. Откройте приложение **App Store** на вашем Mac.
2. В поиске введите `Xcode` и нажмите "Скачать" (установка может занять некоторое время, так как программа весит около 10-12 ГБ).

### Шаг 2: Создайте проект Xcode
Так как этот репозиторий содержит только исходный код (для чистоты), нам нужно быстро собрать проект:
1. Откройте **Xcode**.
2. Нажмите **Create a new Xcode project**.
3. Выберите **iOS** -> **App** и нажмите Next.
4. Введите название: `CalorieTracker`.
5. Interface: **SwiftUI**, Language: **Swift**.
6. Нажмите Next и сохраните проект в удобное место.

### Шаг 3: Перенесите код
1. Удалите файлы, которые Xcode создал по умолчанию (например, `ContentView.swift`, `CalorieTrackerApp.swift`), кроме папки `Assets.xcassets`.
2. Перетащите в левую панель Xcode (Project Navigator) все папки из скачанного репозитория (папки `App`, `Models`, `ViewModels`, `Views`, `Managers`, а также файлы локализации из `Resources`).
3. Убедитесь, что при перетаскивании стоит галочка **"Copy items if needed"**.

### Шаг 4: Настройте разрешения (ОЧЕНЬ ВАЖНО)
Нашему приложению нужны камера (для штрихкодов) и доступ к Apple Health.
1. Нажмите на главный файл проекта `CalorieTracker` (синяя иконка) слева.
2. Перейдите во вкладку **Info**.
3. Нажмите плюсик (Add) и добавьте следующие ключи:
   - `Privacy - Camera Usage Description`: Введите текст (например: "Нужен доступ для сканирования штрихкодов").
   - `Privacy - Health Share Usage Description`: "Нужен доступ для чтения активности".
   - `Privacy - Health Update Usage Description`: "Нужен доступ для записи калорий и воды".
4. Перейдите во вкладку **Signing & Capabilities**.
5. Нажмите кнопку **+ Capability** (в левом верхнем углу).
6. Найдите **HealthKit** и добавьте его (это обязательно для работы с Apple Health).

### Шаг 5: Подключите ваш бесплатный Apple ID
1. В верхнем меню Xcode нажмите `Xcode` -> `Settings` -> вкладка `Accounts`.
2. Нажмите на `+` внизу слева -> `Apple ID` и войдите под своим обычным Apple ID (который используется на телефоне).
3. Закройте настройки.
4. Вернитесь в настройки проекта (вкладка **Signing & Capabilities**).
5. В разделе `Team` выберите свой аккаунт (Там будет написано ваше имя + "Personal Team").
6. Xcode может попросить зарегистрировать устройство — соглашайтесь. *Возможно, появится ошибка про Bundle Identifier — просто добавьте пару случайных цифр в поле "Bundle Identifier" (например: com.yourname.CalorieTracker123), чтобы сделать его уникальным.*

### Шаг 6: Установка на iPhone
1. Разблокируйте ваш iPhone и подключите его к Mac с помощью кабеля. (На телефоне нажмите "Доверять этому компьютеру").
2. В верхней части окна Xcode, рядом с кнопкой ▶ (Play), выберите ваш подключенный iPhone из списка устройств.
3. Нажмите кнопку **▶ (Run)** или `Cmd + R`.
4. Xcode скомпилирует приложение и установит его на телефон.

### Шаг 7: Разрешение на iPhone (только для первого раза)
При первой попытке открыть приложение на iPhone вы увидите сообщение "Ненадежный разработчик".
1. На iPhone зайдите в **Настройки** -> **Основные** -> **VPN и управление устройством** (или "Профили и управление устройством").
2. Найдите там свой Apple ID.
3. Нажмите **Доверять**.

**Готово!** Вы можете пользоваться приложением. 

> ⚠️ **Важно:** Приложения, установленные через бесплатный аккаунт (Personal Team), работают ровно 7 дней. Через 7 дней приложение перестанет открываться. Вам просто нужно будет снова подключить телефон к Mac и еще раз нажать кнопку ▶ (Run) в Xcode. Все ваши данные (включая сохраненные в Apple Health) останутся на месте!
